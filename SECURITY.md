# Security

HALA is a synthetic-only development fixture, not a student-facing assessment service.
Use localhost and fabricated responses only. Same-user worker/gateway processes do not provide OS-identity isolation. Do not expose either demo directly to the internet or connect a live LLM with host tools.

Report vulnerabilities privately to **info@pyragogy.org**. Include the affected commit, minimal synthetic reproduction and expected/actual behaviour. Never post credentials, participant records or exploit details involving third parties in public issues.
There is no promised response time, paid support or bug bounty.

GitHub Actions remain intentionally disabled. Run local/VPS checks; do not add workflows or paid infrastructure without owner authorization.
