# HALA assessment kit v0.1.1

**Draft for synthetic rehearsal and external critique · 10 October 2026**  
No participant study, validated scores or scientific signoff. English drafting version; translation and accessibility review pending.

A small way to challenge HALA's central distinction: an impressive assisted answer and a learner's independently demonstrated reasoning are different evidence.

## Start in ten minutes

1. Read the fictional [tasks](TASKS.md).
2. Score the final responses in the [blind packet](BLIND_RESPONSES.md) using the [rubric](RUBRIC.md), without looking at proposed anchors.
3. Open [the cases](SYNTHETIC_CASES.md) and each case's provenance and independent response. Ask whether your interpretation changes.
4. Record disagreements using [the review sheet](review_sheet.csv) and [review questions](REVIEW.md).

This is a document-based rehearsal, not an executable learner application. Every scenario, number, transcript and answer is authored as a synthetic fixture. None is observed participant data.

## What this kit proposes to describe

**Target:** task-specific evidence reasoning: distinguish an observed difference from a causal effect, use supplied evidence, explain a bounded conclusion, and propose a discriminating check.

**Allowed interpretation:** a rater's ordinal description of the reasoning displayed in this response under its documented conditions.

**Unsupported interpretations:** general intelligence, a stable epistemic trait, verified learner authorship, improvement caused by AI, validated EQI, PISA proficiency or demonstrated retention.

The four dimensions retain the existing [item blueprint](../ITEM_BLUEPRINT.md). This kit supplies task-specific anchors; it does not adopt a new endpoint or replace [P01](../../research/PROTOCOL_V1.md).

## Contents and boundaries

| Material | Role | Boundary |
| :--- | :--- | :--- |
| Task L: library programme | Candidate assisted learning exercise | No B/C intervention tested or frozen |
| Task I: reflective roof coating | Candidate independent post-session exercise | Not equated with L or a baseline form |
| Ten synthetic cases | Expose false interpretations and rubric weaknesses | Proposed anchors are authored expectations, not human reference labels |
| Challenges R/U | Bounded causal trust and uncertainty | Synthetic rubric controls, not adopted study outcomes |
| Rubric and review sheet | Make ratings and disagreements inspectable | No reliability coefficient or cutoff has been established |
| Review questions | Prepare a narrow external assessment critique | No reviewer recruited or endorsement implied |

A full study still needs T0, reviewed forms, controlled interventions, independent T2 conditions, separate T3 transfer tasks and actual T4 at 7–14 days, plus the protocol's scientific, ethics and safety gates. A different story using the same causal structure is not established far transfer.

**These tasks and answers are public.** They must not serve as secret held-out assessments in a future trial. Future protected forms need different content, reviewed comparability and controlled access. Do not put those protected items or personal learner records in Git.

Independent challenge and owner adjudication remain pending. The immediate useful result is a documented disagreement or counterexample, not a favorable score.
