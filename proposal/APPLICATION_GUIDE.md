## Application package (provisional, not asserted mandatory)
1. Cover message with proposer identity and institutional status accurately stated.
2. Two-page concept note: problem, innovative contribution, PISA relevance, research questions, intended outputs, readiness/limits.
3. Study protocol: three-arm design, independently measured outcomes, risks, ethical safeguards and phased pilot.
4. Demonstrator evidence: synthetic-only pipeline, source code and test runs; explicitly not educational efficacy evidence.
5. Capacity and resources: documented work, team roles vs *actually recruited* collaborators, bounded milestones, no remuneration assumption.
6. Data, security and intellectual-property statement, conditional on official requirements.
