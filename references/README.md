## Source handling

This folder contains original notes and bibliographic metadata, with links to publishers and author repositories. It does not redistribute third-party papers, student transcripts or the restricted OECD call. Linked materials retain their own rights; HALA's licenses do not apply to them.

For each source's access level, findings and limitations, consult the review. Keep future additions dated and explain whether the full methods, selected sections, abstract or metadata were actually read.
