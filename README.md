# Human–AI Learning Assessment (HALA)

**Status:** research protocol in development — not a validated assessment instrument.

## Research question

How can we measure the **quality and durable improvement of student learning** through collaboration with AI, distinguishing assisted performance from independently acquired competence?

## Core principles
1. Measure learning, not merely the quality of AI-assisted output.
2. Separate observations, measurements, interpretations and causal claims.
3. Use independent pre/post, transfer and delayed retention tests.
4. Compare AI collaboration with meaningful control conditions.
5. Treat all proposed indices, including EQI, as unvalidated until psychometric studies support them.
6. Preserve learner autonomy, privacy, informed consent and auditability.

## Working study design
- **A — Control:** comparable non-AI learning materials and equal instructional time.
- **B — AI tutor:** supportive, explanatory tutor.
- **C — Critical collaborative AI:** agent asks questions, challenges reasoning and prompts verification.
- **T0:** independent baseline.
- **T1:** supervised learning session, with interactions logged by consent.
- **T2:** independent post-test using equated items.
- **T3:** independent novel-problem transfer test.
- **T4:** delayed independent retention test (7–14 days).

Primary endpoint: difference in independent post-test learning gains between randomly allocated conditions, adjusted for baseline. Secondary endpoints include transfer, retention and coded collaboration processes. A pilot first examines feasibility, not efficacy.
